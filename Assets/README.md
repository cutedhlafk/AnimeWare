# Pochodzenie zasobów

Inter Regular i SemiBold oraz ikony SVG zostały wydzielone z pliku cs2.dll dostarczonego przez użytkownika. Identyfikatory w nazwach ikon odpowiadają offsetom w pliku źródłowym. Inter identyfikuje się w metadanych jako Inter Project / Rasmus Andersson, na licencji SIL Open Font License 1.1: https://openfontlicense.org/ .

Ikony są tymczasowymi zasobami interfejsu. Docelowe grafiki i identyfikację wizualną dostarczy użytkownik. Pliki PNG odzyskanego logo nie są wykorzystywane w interfejsie nowej aplikacji.
